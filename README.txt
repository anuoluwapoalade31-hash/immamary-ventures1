IMMA MARY VENTURES WEBSITE

Files:
- index.html: website content
- style.css: styling and responsive layout
- script.js: mobile menu, savings estimator, and footer year
- images/ceo-israel.png: uploaded CEO portrait

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a web browser. An internet connection is needed for the online hero background and Google Fonts; the CEO portrait is stored locally.

BEFORE PUBLISHING
- The email contact button opens a message to the CEO’s email address without displaying the address on the webpage.
- Add a real business phone number if you want a WhatsApp/call button.
- Replace service descriptions and any future impact figures with verified information about your actual operations.
- The savings estimator is illustrative only and should not be treated as a quote or guaranteed saving.
